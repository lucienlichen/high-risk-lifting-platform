## 一、项目概述

### 1.1 项目背景

高风险起重装备广泛应用于冶金、港口、建筑工地、船舶制造等行业，设备运行安全直接关系到人员生命和生产安全。本平台旨在通过物联网传感采集、数字孪生推演、智能算法分析等技术手段，实现起重装备全生命周期的智能运维与事故防控。

### 1.2 项目目标

- 建立覆盖冶金、港口、建筑工地、船舶制造四大场景的起重装备监管体系
- 提供远程监测、健康评估、裂纹预测、故障诊断等智能运维服务
- 提供风险监测、隐患排查、问题处理等事故防控服务
- 支持多层级组织架构（集团—子公司—设备）的设备管理
- 建立完善的后台管理体系，支撑平台运营

### 1.3 技术架构

- **前端**：Vue 3 + TypeScript + Vite + Element Plus + ECharts 5
- **后端**：Spring Boot 3
- **数据库**：关系型数据库（核心表：用户/角色/组织/场景/设备）
- **认证**：JWT 签发/验证/刷新

### 2.5 远程监测服务（已完成）

#### 2.5.1 功能描述

以 Bottom Drawer 形式展开，占据设备详情页大部分区域，提供实时监测报警和历史预警记录两种模式。

#### 2.5.2 实时监测报警

分为两列布局：

**参数监控（左列，8项）**：起重量、起重力矩、起升高度/下降深度、运行行程、幅度、大车运行偏斜、风速、回转角度

**状态监控（右列，8项）**：起升机构制动器的开闭、抗风防滑、联锁保护、门限位、机构之间的运行联锁、同一或不同一轨道运行机构安全信号、供电电缆卷筒、超速保护

每个监测卡片显示：监测项名称、当前值、限值/说明、状态标签（正常/告警）、状态指示灯（正常绿色/告警红色闪烁）。告警状态卡片可点击弹出报警处理对话框（忽略/已处理）。

#### 2.5.3 历史预警记录

- 切换按钮：未处理记录 / 历史记录
- 告警表格字段：发生时间、告警级别（危险/警告/提示）、告警来源、监测参数、告警内容、实时值、阈值/期望、持续时长、当前状态
- 历史记录额外字段：峰值、处理结论、处理人、处理时间
- 可展开行查看告警趋势图表（ECharts 曲线 + 限值标线）
- 支持一键消警、单条处理告警

## 三、管理端需求

### 3.1 登录页

#### 3.1.1 功能描述

平台统一登录入口，支持账号密码登录。

#### 3.1.2 页面内容

- 平台品牌展示区（左侧/背景）：平台名称、宣传语、背景图
- 登录表单区（右侧）：用户名输入框、密码输入框（带显隐切换）、记住密码勾选、登录按钮
- 表单验证：用户名/密码非空校验，密码长度校验
- 登录流程：调用JWT认证接口 → 获取Token → 存储Token → 跳转至主页面

#### 3.1.3 安全要求

- 密码输入支持明文/密文切换
- 登录失败显示错误提示
- Token过期自动跳转登录页

#### 3.10.2 页面内容

- **规则列表**：规则名称、适用场景、适用设备类型、监测参数、告警条件、告警级别、状态、操作
- **新增/编辑规则**：规则名称、适用场景（多选）、适用设备类型（多选）、监测参数选择、告警条件（大于/小于/等于/区间）、阈值配置、告警级别、通知方式（平台通知/短信/邮件）、是否启用

## 四、非功能性需求

### 4.1 性能要求

- 页面首屏加载时间 ≤ 3秒
- 设备列表（1000+条）渲染流畅，支持虚拟滚动
- ECharts图表渲染 ≤ 500ms

### 4.2 兼容性

- 支持 Chrome 90+、Firefox 90+、Edge 90+
- 最低分辨率支持 1280×720，推荐 1920×1080

### 4.3 安全性

- 前端路由鉴权 + 按钮级权限控制
- JWT Token + Refresh Token 双 Token 机制
- 敏感接口防重放

### 4.4 代码规范

- 使用 Vue 3 Composition API + `<script setup>` 语法
- TypeScript 严格模式
- CSS 变量统一管理设计令牌
- 组件命名 PascalCase，文件命名 PascalCase
